# Student Management System

This is a simple Student Management System I built using Python and SQLite as part of my Python learning journey.

The main purpose of this project is to manage student records through a menu in the terminal.

## What it can do

* Add a new student
* View all students
* Search for a student by name
* Update student details
* Delete a student record
* Validate user input, including student IDs and email addresses

## Built With

* Python
* SQLite

## Project Files

* `main.py` – Contains the main menu and application logic.
* `database.py` – Handles the database operations.
* `.gitignore` – Keeps files such as the local database out of Git.

## How to Run

You need Python installed on your computer.

1. Clone this repository:

   ```bash
   git clone https://github.com/Mohammedanas461/student-management-system.git
   ```

2. Open the project folder:

   ```bash
   cd student-management-system
   ```

3. Run the program:

   ```bash
   python main.py
   ```

On Windows, you can also try `py main.py`.

The program uses SQLite to store student records locally.
